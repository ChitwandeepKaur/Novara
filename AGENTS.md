# ASCEND project conventions

## User-visible writing

Do not use the Unicode U+2014 em dash in any user-visible app text, generated task heading, placeholder, or imported plan label. Use a colon, comma, parentheses, or a separate sentence instead. Normalize imported plan text before displaying it. Preserve URLs and original external file contents.

## Version control

Commit completed changes with clear messages describing the behavior and push them to the configured Git remote. Never add AI authorship, generator credit, or assistant co-author trailers to source code or commits. Do not overwrite existing authorship or license notices. Do not commit secrets, signing keys, device data, or local user settings.
